# Code of Conduct

## Our standard

We want this project to be a respectful, welcoming place to work on energy management software. Be kind, be patient with newcomers, give and accept feedback constructively, and assume good faith. Harassment, discrimination, personal attacks, and publishing other people's private information are not acceptable.

## Adopted standard

This project adopts the **Contributor Covenant, version 3.0**, by reference:
<https://www.contributor-covenant.org/version/3/0/code_of_conduct/>

The Covenant is published by the Organization for Ethical Source under its own licence. We link to it rather than copy its text. The summary above is written in our own words; where the two differ, the Covenant's wording governs. This project is not affiliated with the Organization for Ethical Source.

## Scope

This applies to all project spaces: the issue tracker, pull requests, discussions, and any other place where someone is representing the project.

## Reporting

To report a conduct concern, email **aurexcv@gmail.com**. Please include what happened, where, and who was involved. Reports are handled privately and read by the maintainer.

For security vulnerabilities, do not use this address; see [SECURITY.md](SECURITY.md).

## Enforcement

The maintainer (Aurex, `aurex-ke`) is responsible for clarifying and enforcing this code. Responses may include a private note, a request to edit or remove a comment, a temporary or permanent restriction from project spaces, or no action. The maintainer may act on conduct outside the listed rules where it affects the community. This is a one-person project, so if your concern is about the maintainer, say so in your report and we will look for an independent route.
